3. Parse 'DT_STRATA' to datetime and format as '%a %m/%d/%Y' in column 'cst'.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
```

### Example 2 (Case length2_1)
Source Schema: CST (object), 1:00..24:00:00 (float64)
Target Schema: dt_strata (object), dow (int64), pct_hourly_0100..pct_hourly_2500 (float64)
Source Sample: CST sample: ['Sat 12/01/2012', 'Sun 12/02/2012']; 1:00 sample: [0.9841, 0.9012]
Target Sample: dt_strata sample: ['04/01/2009', '04/02/2009']; dow sample: [3, 4]; pct_hourly_0100 sample: [1.02, 0.93]
Step-by-Step Reasoning Plan:
1. Inspect date: Source 'CST' has format 'Day MM/DD/YYYY'. Split by whitespace to extract the date part.
2. Convert to datetime, then format as '%m/%d/%Y' for 'dt_strata'.
3. Compute 'dow' (day of week) where Monday=1 ... Sunday=7 using `dt.dt.dayofweek + 1`.
4. Rename hourly columns: '1:00' -> 'pct_hourly_0100', ..., '24:00'/'24:00:00' -> 'pct_hourly_2400'.
5. Target includes 'pct_hourly_2500' filled with 0. Add this column and select target columns verbatim.
Generated Code:
```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    df = source.copy()
    date_str = df['CST'].str.split(' ').str[-1]
    dt = pd.to_datetime(date_str, format='%m/%d/%Y')
    df['dt_strata'] = dt.dt.strftime('%m/%d/%Y')
    df['dow'] = dt.dt.dayofweek + 1
    rename_dict = {f'{i}:00': f'pct_hourly_{i:02d}00' for i in range(1, 24)}
    if '24:00:00' in df.columns:
        rename_dict['24:00:00'] = 'pct_hourly_2400'
    elif '24:00' in df.columns:
        rename_dict['24:00'] = 'pct_hourly_2400'
    df = df.rename(columns=rename_dict)
    df['pct_hourly_2500'] = 0
    target_cols = ['dt_strata', 'dow'] + [f'pct_hourly_{i:02d}00' for i in range(1, 26)]
    return df[target_cols]
```

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    df = source.copy()
    dt = pd.to_datetime(df['DT_STRATA'])
    df['date'] = dt.dt.strftime('%m/%d/%Y')
    rename_dict = {f'PCT_HOURLY_{i:02d}00': f'Hour {i}' for i in range(1, 25)}
    df = df.rename(columns=rename_dict)
    target_cols = ['date'] + [f'Hour {i}' for i in range(1, 25)]
    return df[target_cols]
```
